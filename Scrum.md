## Sprints

### Sprint 1 (07/10 a 13/10): Base
- **Meta:** criar a estrutura do projeto e o esqueleto das abas.
- **Tarefas:** definir o padrão visual e montar o HTML e CSS inicial de cada aba. O código ficou armazenado localmente na máquina de cada dev.
- **Resultado:** ✅ estrutura criada e todas as abas iniciadas (versão local, sem commits no GitHub).

### Sprint 2 (14/10 a 20/10): Desenvolvimento
- **Meta:** abas com conteúdo final e JavaScript funcionando.
- **Tarefas:** finalizar o conteúdo de cada aba, validar o formulário de agendamento, criar o abrir/fechar das dúvidas e montar os cards da equipe.
- **Resultado:** ✅ todas as abas com conteúdo e interações prontas (ainda armazenadas localmente).

### Sprint 3 (21/10 a 27/10): Fechamento
- **Meta:** site integrado, testado e publicado.
- **Tarefas:** criar o repositório no GitHub e fazer os commits de todas as abas (única semana com commits), integrar a navegação entre as abas, ajustar a responsividade, corrigir bugs e publicar o site.
- **Resultado:** ✅ código commitado no GitHub, site publicado e entregue.

> **Observação importante:** o projeto foi desenvolvido durante as três semanas, mas ficou armazenado localmente. O versionamento no GitHub (commits) só foi feito na última semana, na Sprint 3.

---

## Cerimônias

- **Planning:** no início de cada sprint, pelo Meet.
- **Daily:** conversa rápida durante a sprint.
- **Review:** no fim da sprint, mostrando as abas ao Product Owner.
- **Retrospectiva:** no fim de cada sprint e no final do projeto.

---

## Definição de pronto

Uma aba está pronta quando funciona (HTML, CSS e JS), está commitada no GitHub, aparece no site publicado e foi aprovada pelo Product Owner.

---

## Retrospectiva final

- **O que deu certo:** a divisão por abas deixou cada um com uma responsabilidade clara, e o GitHub facilitou juntar o trabalho de todos.
- **O que pode melhorar:** combinar o padrão de CSS antes de começar as abas e usar o GitHub desde a primeira semana, com commits e merges frequentes, em vez de guardar o código só localmente.
- **Aprendizado:** organizar o trabalho em sprints ajudou a cumprir o prazo e a enxergar o que faltava em cada etapa.
